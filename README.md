# حسابداری پلاس

**نرم‌افزار حسابداری و مدیریت فروشگاه — نسخه ۲۰**

رابط کاملاً فارسی و راست‌به‌چپ برای مدیریت فروش، خرید، انبار، صندوق، چک، پرسنل، شرکا و گزارش‌های مالی. به‌صورت **PWA** روی مرورگر اجرا می‌شود؛ داده روی دستگاه می‌ماند و در صورت تمایل با حساب Google همگام می‌شود.

---

## ویژگی‌ها

| بخش | امکانات |
| --- | --- |
| **فروش** | فاکتور فروش، مشتریان، چاپ فاکتور و پیش‌فاکتور |
| **خرید** | فاکتور خرید، تأمین‌کنندگان، سفارش خرید |
| **کالا و انبار** | کارت کالا، چند انبار، انتقال بین انبار، انبارگردانی |
| **مالی** | صندوق و بانک، چک‌ها، هزینه‌ها، بدهکاران و طلبکاران |
| **پرسنل** | حقوق و دستمزد |
| **شرکا** | سهم سود، سرمایه نقدی و غیرنقدی (ثبت خودکار در صندوق برای سرمایه نقدی) |
| **زنجیره تأمین** | سفارش مجدد، قرارداد، گارانتی، کنترل کیفیت دریافت |
| **گزارش‌ها** | سود و زیان، گردش کالا، موجودی، خلاصه مالی |
| **پشتیبان** | خروجی JSON، پشتیبان دوره‌ای، پوشه محلی، Google Drive |
| **ظاهر** | تم روشن/تاریک، چند رنگ سازمانی، اندازه فونت، فونت‌های فارسی |

## اجرای سریع

```text
1. فایل‌ها را در یک پوشه قرار دهید (یا از همین zip استخراج کنید).
2. با یک سرور استاتیک ساده سرو کنید، مثلاً:

   npx --yes serve .
   # یا
   python3 -m http.server 8080

3. در مرورگر آدرس را باز کنید (مثلاً http://localhost:3000).
```

> برای نصب به‌عنوان اپلیکیشن (PWA) از مرورگر Chrome / Edge گزینه **Install** یا «نصب برنامه» را بزنید.

### فایل‌های اصلی

```text
hesabdari-plus/
├── index.html          # پوسته رابط
├── app.js              # منطق برنامه
├── styles.css          # طراحی سیستم (RTL)
├── manifest.json       # تعریف PWA
├── sw.js               # Service Worker (کش نسخه ۲۰)
├── icons/              # آیکون‌های 192 / 512 / maskable
└── README.md
```

## شروع کار (اولین اجرا)

ویزارد راه‌اندازی پنج مرحله دارد:

1. **نام فروشگاه** و اطلاعات تماس  
2. **نوع استفاده**: خانگی / حرفه‌ای / چندشعبه‌ای / فروش آنلاین  
3. **نوع شغل / صنف** (پوشاک، دیجیتال، سوپرمارکت، …)  
4. **مالکیت**: تک‌نفره یا شراکتی + درصد سهم  
5. **واحد پول**، مالیات و بارگذاری دادهٔ نمونه (اختیاری)

اگر قبلاً با Google وارد شده‌اید، همان ابتدا می‌توانید وارد شوید تا داده ابری بازیابی شود.

## نکات مهم کاربری

### سرمایه شرکا و صندوق
- سرمایه **نقدی (تومان)** با ثبت در بخش شرکا، خودکار به‌عنوان ورود وجه در **صندوق** ثبت می‌شود — دوباره دستی وارد نکنید.
- سرمایه **غیرنقدی** (طلا، ارز، …) فقط به‌عنوان دارایی شریک ثبت می‌شود و موجودی نقد را تغییر نمی‌دهد.

### چند انبار
هر فروشگاه یک **انبار اصلی** دارد. از مسیر  
**کالا و انبار → مدیریت انبارها** می‌توانید انبار/شعبه اضافه کنید، موجودی تفکیک‌شده ببینید و کالا جابه‌جا کنید.

### پشتیبان‌گیری
- خروجی فایل JSON از بخش **پشتیبان‌گیری**
- نگه‌داری نسخه‌های روزانه در IndexedDB
- در مرورگرهای سازگار: انتخاب پوشه برای ذخیره خودکار
- همگام با **Google Drive** (مجوز Drive فقط هنگام استفاده از این گزینه درخواست می‌شود)

### ورود با Google
- ورود عادی فقط هویت Google را می‌گیرد.
- داده عملیاتی محلی در `localStorage` است؛ همگام‌سازی ابری با Firebase Authentication و Firestore انجام می‌شود.

## مشخصات فنی

| مورد | توضیح |
| --- | --- |
| نوع | Single-page application + PWA |
| زبان رابط | فارسی، `dir="rtl"` |
| ذخیره محلی | `localStorage` + IndexedDB (پشتیبان‌های دوره‌ای) |
| آفلاین | Service Worker با استراتژی network-first برای فایل‌های برنامه |
| احراز هویت ابری | Firebase Authentication (Google) |
| همگام‌سازی | Firestore (در صورت پیکربندی پروژه) |
| کش SW | `hesabdari-plus-v20` |

مرورگرهای پیشنهادی: Chrome، Edge، Firefox نسخه‌های اخیر (دسکتاپ و موبایل).

## رابط دسکتاپ و موبایل

- **دسکتاپ (≥۹۰۰px):** منوی کناری ثابت با اسکرول مستقل؛ ارتفاع منو با `visualViewport` هم‌تراز می‌شود تا همهٔ بخش‌ها (از جمله تنظیمات) با غلطک موس در دسترس باشند.
- **موبایل:** نوار پایین + منوی «بیشتر» به‌صورت کشو.

## توسعه و سفارشی‌سازی

پروژه وابستگی npm ندارد؛ با ویرایش مستقیم فایل‌ها قابل توسعه است.

| فایل | نقش |
| --- | --- |
| `app.js` | viewها، ویزارد، فاکتور، گزارش، پشتیبان، همگام‌سازی |
| `styles.css` | توکن‌های طراحی، تم‌ها، layout، چاپ |
| `sw.js` | نسخه کش — با هر انتشار عمومی نام `CACHE_NAME` را بالا ببرید |
| `manifest.json` | نام، آیکون، `theme_color` |

پس از تغییر کد، یک بار **Hard Refresh** (`Ctrl+F5`) بزنید تا Service Worker نسخه جدید را بگیرد.
